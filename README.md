# นำแอป POS ไปใช้จริงบนมือถือ (วิธีง่ายสุด ไม่ต้องยุ่งกับโฟลเดอร์)

โปรเจกต์นี้จงใจทำให้ไฟล์ทุกไฟล์อยู่ "แถวเดียวกันหมด" ไม่มีโฟลเดอร์ย่อยเลย
เพื่อกันปัญหาลากไฟล์/โฟลเดอร์แล้วโครงสร้างเพี้ยนแบบที่เจอมา

Supabase ตั้งค่าให้เรียบร้อยแล้ว (ใส่ URL + key ไว้ในไฟล์ `supabaseConfig.js` แล้ว) ไม่ต้องแก้อะไรเพิ่ม

---

## ขั้นตอนที่ 1 — สร้าง repo ใหม่บน GitHub (ทิ้งอันเก่าไปเลย)

1. เปิด repo เก่า `little-duck-pos` บน GitHub → ไปที่ **Settings** (แท็บบนสุดของ repo) → เลื่อนลงล่างสุด → **Delete this repository** → พิมพ์ชื่อ repo ยืนยัน → ลบทิ้ง
   (หรือจะสร้าง repo ใหม่ชื่ออื่นแทนก็ได้ ไม่ต้องลบอันเก่าก็ได้ แล้วแต่สะดวก)
2. กด **New repository** → ตั้งชื่อ เช่น `bakery-pos` → **Create repository** (อย่าติ๊กเพิ่ม README ตอนสร้าง ปล่อยว่างไว้)

## ขั้นตอนที่ 2 — อัปโหลดไฟล์ (เลือกทีละไฟล์ ไม่ต้องลากโฟลเดอร์)

1. ในหน้า repo ใหม่ กด **uploading an existing file** (หรือ Add file > Upload files)
2. กดที่คำว่า **"choose your files"**
3. ในหน้าต่างเลือกไฟล์ที่เปิดขึ้นมา ให้ **กด Ctrl ค้างไว้ (Windows) หรือ Cmd ค้างไว้ (Mac) แล้วคลิกเลือกไฟล์ทั้ง 7 ไฟล์นี้พร้อมกันทีเดียว**:
   - `App.jsx`
   - `main.jsx`
   - `storage.js`
   - `supabaseConfig.js`
   - `package.json`
   - `vite.config.js`
   - `manifest.json`
   - `index.html`
   - `README.md`
   (รวม 9 ไฟล์ ไม่มีโฟลเดอร์ให้ลากเลยสักอัน)
4. กด **Open**
5. กด **Commit changes**

## ขั้นตอนที่ 3 — เช็กให้ชัวร์ก่อนไป Netlify

เปิดหน้า repo อีกครั้ง ต้องเห็นไฟล์ **9 ไฟล์เรียงแถวเดียวกันหมด ไม่มีไอคอนโฟลเดอร์สีน้ำเงินเลยสักอัน** ถ้าเห็นแบบนี้แปลว่าถูกต้อง พร้อมไป Netlify ได้เลย

## ขั้นตอนที่ 4 — Deploy ผ่าน Netlify

1. เปิด **https://netlify.com** → สมัคร/ล็อกอินด้วยบัญชี GitHub เดียวกัน
2. กด **Add new site > Import an existing project**
3. เลือก **GitHub** → เลือก repo ที่เพิ่งอัปโหลด (`bakery-pos`)
4. ตั้งค่า build (ปกติ Netlify เดาให้อัตโนมัติ แต่เช็กให้ตรงนี้):
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
5. กด **Deploy site** → รอ 1–2 นาที จะได้ลิงก์ เช่น `https://your-site-name.netlify.app`

## ขั้นตอนที่ 5 — ติดตั้งเป็น "แอป" บนมือถือ

เปิดลิงก์จากขั้นตอนที่ 4 บนมือถือ:
- **iPhone (Safari):** กดปุ่มแชร์ → **Add to Home Screen**
- **Android (Chrome):** กดจุดสามจุดมุมขวาบน → **Add to Home screen / Install app**

## ถ้ามีการแก้โค้ดเพิ่มในอนาคต

ผมจะส่งไฟล์ที่แก้ (เช่น `App.jsx` เวอร์ชันใหม่) มาให้ทีละไฟล์
วิธีอัปเดต: เปิดไฟล์นั้นบน GitHub → กดดินสอ (Edit) → ลบเนื้อหาเดิมทั้งหมด → วางโค้ดใหม่ทับ → Commit changes
ไม่ต้องอัปโหลดใหม่ทั้งโปรเจกต์ Netlify จะ build ให้อัตโนมัติเองภายใน 1-2 นาที
